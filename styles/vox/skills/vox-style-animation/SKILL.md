# Vox-style animation (editorial collage explainer)

Craft distilled from Vox producers and alumni, tutorial literature, broadcast standards and frame
and audio measurements of 28 reference reels (`inspirations/`). Flat-vector explainers
(Kurzgesagt) are a different school.

**Project overlay.** Identity (palette, type, materials), audience, voice, outro and any bridge
line to a product belong to the project's overlay skill; where it says so, it overrides this
skill. Craft norms below hold unless the overlay names the departure.

## The contract

One **question** → **evidence on screen** → one **insight**. Texture, cut-outs, camera and SFX
exist only to make the evidence legible and trusted. Each beat is a mini-proof:
*claim (voice) → object (screen) → mark (one accent) → hold (time to read)*.

## Defaults

| Dimension | Norm |
|---|---|
| Length | Reels 45–60 s (90 max); hook said whole by 4.5 s; turn at 40–60 % |
| Cadence | dynamic, not frantic: average shot 1.6–3.2 s; hero held 3–8 s, at least twice ≥ 5 s; < 1.5 s only under a spoken list |
| Frame | ≤ 3 elements (hero, caption, one annotation); 1 accent mark; ≤ 2 accent colours per film |
| Text | caption 2–4 words, word-synced, one fixed lower position (above the bottom UI zone); one giant hero word (1–3 words) per idea; never a sentence |
| Evidence | every noun gets its literal object; real cut-outs, scans, documents; never code-drawn props |
| Ground | never flat, never a gradient, never pure black: graded scan, lifted blacks, one tint, scaled grain |
| Camera | slow push into evidence; travel or cut when the noun changes; whips ≤ 3 per film |
| Sound | voice wall to wall; bed ~20 dB under speech or none; SFX ≤ 1 per 4–6 s, 12 dB under speech + sidechain duck; -14 LUFS, LRA ≤ 3 |
| Safe zones | 1080×1920: top 220, bottom 400, right rail 140 from y 1100 |
| Presenter | optional: 2–4 talking-head cutaways of 3–4 s as a pace reset, never the backbone |

## Workflow

| Step | Do | Load |
|---|---|---|
| 1 Script | question, hook, turn, payoff, CTA; three columns ears / eyes / sources | **REQUIRED SUB-SKILL:** `explainer-script` |
| 2 Evidence | find the key document; collect the literal object for every noun; verify | `references/principles.md` |
| 3 Design | grounds, grade, cut-outs, type tiers, marks, palette | `references/visual-language.md` |
| 4 Animate | camera language, easing, stepped motion, transitions, holds | `references/motion-and-camera.md` |
| 5 Build | style components on the engine | `references/components.md`, `motion-engine` |
| 6 Sound | voice first, bed, sparse SFX, mix numbers | `references/sound.md` |
| 7 Review | scored rubric + hunt list, ≥ 3 rounds | **REQUIRED SUB-SKILL:** `vox-critic` |

## Red flags (stop and fix)

- A shot that changes without the voice changing noun.
- A picture that fits the mood but does not prove the line.
- Two marks, two text blocks or a caption over the proof.
- A flat or gradient ground; everything fading in; punch-in zooms.
- SFX audible over a word; a stinger at the end; a dense outro dump.

The "Vox moves" (match cut, page turn, gate weave, counters, map route, stepped 12 fps, …) are
tools, not a quota: use the one the sentence needs. A clear film with six moves beats a busy one
with twelve. Sources with URLs: `references/sources.md`.
