# Zhylin: Vox lessons for the director

Source: Denys Zhylin, tutorial notes in tutorials/zhylin-five-vox-tricks.md (timestamps as given).

1. When the brief promises a count ("five tricks"), the count is a fact to check at each gate: the script has N chapters, the sheet has N cards, the render shows N cards (0-1.5 s promise, 4-56 s delivery).
2. Build the shared chapter card once, before the beats that use it, and route every card through that one asset (takeaway 2).
